3. **Fine-tuning (імітація)** — чудово задає формат відповіді та стиль, але вимагає підготовки прикладів.

## 2. Завдання 8. Практичний вибір підходу

### Ситуація 1: Генератор рекламних текстів зі строгою структурою
* **Обраний підхід:** **Fine-tuning** (або Few-shot Prompting)
* **Обґрунтування:** Навчання на прикладах найкраще підходить для закріплення специфічного стилю бренду, тональності та суворого дотримання структури тексту.

### Ситуація 2: Чат-бот за внутрішньою документацією компанії
* **Обраний підхід:** **RAG**
* **Обґрунтування:** Документація компанії постійно оновлюється. RAG дозволяє шукати точну інформацію в актуальних файлах без перенавчання моделі та дає посилання на джерела.

### Ситуація 3: Адаптація моделі під специфічний стиль на основі багатьох прикладів
* **Обраний підхід:** **Fine-tuning**
* **Обґрунтування:** Fine-tuning змінює внутрішні ваги моделі, що дозволяє їй природно відтворювати необхідний авторський стиль без витрачання токенів на довгі промпти.
